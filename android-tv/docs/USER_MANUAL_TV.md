# 用户手册 — 小趴菜 TVOS 版家长控制

## 安装与初始化

### 首次安装

1. 将 `app-debug.apk` 通过 USB 或网络传输到电视
2. 在电视上打开文件管理器，找到并安装 APK
3. 电视系统会提示"安装未知应用"，授权安装

### 首次启动

1. 打开小趴菜 TVOS 应用
2. 系统提示授予以下权限：
   - **使用统计权限**：用于追踪各应用使用时长
   - **忽略电池优化**：防止系统杀死后台服务
   - **通知权限**：接收告警和提醒
3. 按引导逐一授权

## 功能说明

### 1. 首页

显示当前设备状态：
- 今日剩余使用时间
- 已用时长和每日限额
- 已安装应用列表
- 设置入口

### 2. PIN 密码设置

家长可在设置中设置 4-6 位 PIN 密码：
- PIN 密码使用 SHA-256 哈希存储，不可逆
- 用于解锁超时锁屏、修改设置
- 支持云端远程修改 PIN

### 3. 限额设置

- **每日限额**：设置设备每日最大使用时间（分钟）
- **白名单应用**：指定不计入限额的应用（如 YouTube Kids）
- **就寝时段**：指定每天不可使用的时段范围

### 4. 豁免请求

当孩子在限额内但仍需要更多时间时：
1. 在首页点击"申请更多时间"
2. 选择需要延长的时长（15/30/60 分钟）
3. 请求发送至云端，家长 APP 实时收到通知
4. 家长批准后自动延长限额

### 5. 锁屏

当使用时间达到限额时：
1. 显示全屏锁屏覆盖层
2. 显示已用时长、剩余时间（0）、锁定原因
3. 家长输入 PIN 密码解锁
4. 或等待次日自动重置

### 6. 云端公告

家长可通过云端下发通知消息：
- 在心跳响应中携带 `announcement` 字段
- 应用自动弹出公告显示
- 支持富文本样式

## 安全机制

### 防绕过

小趴菜 TVOS 版通过以下方式防止孩子绕过限制：

1. **后台持续监控**：防绕过服务每 5 秒检查一次
2. **应用完整性检测**：监控应用是否被卸载或禁用
3. **网络状态监控**：网络断开时暂停云端同步
4. **多用户会话监控**：检测电视多用户切换

### 篡改告警

检测到以下异常时，自动向云端发送告警：

| 检测项 | 触发条件 | 告警内容 |
|--------|---------|---------|
| 守护服务关闭 | CloudSyncService/AntiBypassService 被杀 | "守护服务已停止" |
| 调试模式开启 | `adb devices` 连接 | "USB 调试已启用" |
| 应用被禁用 | 应用包状态变为 disabled | "应用已被禁用" |
| 统计权限撤销 | `QUERY_ALL_PACKAGES` 被移除 | "使用统计权限已撤销" |

## 故障排查

### 应用被系统杀死

**症状**：限额不生效，锁屏不显示

**解决**：
1. 设置 → 应用 → 小趴菜 TVOS → 电池 → 无限制
2. 在 MIUI TV 中开启"自启动"权限
3. 在安全中心将应用加入白名单

### PIN 密码遗忘

**症状**：锁屏后无法解锁

**解决**：
1. 通过云端远程重置 PIN（家长 APP）
2. 心跳同步后，云端新 PIN 自动生效
3. 清除应用数据（最后手段，会丢失本地配置）

### 云端同步失败

**症状**：限额/白名单变更未生效

**解决**：
1. 检查电视网络连接
2. 手动触发心跳（设置 → 同步）
3. 检查云端服务器状态

## 常见问题

**Q: 支持哪些电视品牌？**
A: 任何运行 Android TV 8.0+ 或 Google TV 的设备。包括索尼、NVIDIA Shield、Chromecast、TCL 雷鸟等。小米电视需要额外配置。

**Q: 是否支持多用户？**
A: 目前应用为单用户设计。电视系统多用户切换时，应用状态不会重置。

**Q: 离线状态下如何使用？**
A: 离线状态下限额和锁屏功能正常工作。云端同步在有网络后自动恢复。

**Q: 数据是否安全？**
A: PIN 密码使用 SHA-256 哈希存储，不会明文保存。设备 ID 使用 UUID，不关联个人身份信息。
