# 小趴菜 P2P 连接演示指南

> [TASK-D1-04] 本文档指导测试工程师如何验证 P2P 连接的完整生命周期。

## 测试环境准备

### 家长端（Windows 50.20）
1. 安装 .NET 8 SDK
2. 进入 `windows/XiaopacaiParent/` 目录
3. 执行 `dotnet run` 启动家长端

### 儿童端（Android / 模拟器）
1. 安装 Android Studio + Android SDK 34
2. 进入 `android/` 目录
3. 执行 `./gradlew installDebug` 安装 APK
4. 启动小趴菜应用

## 演示场景

### 场景 A：发现 → 配对 → 握手

```
步骤1: 家长端启动
  → 自动生成自签名证书
  → 生成 6 位配对码（如 "482931"）
  → 显示配对二维码（含设备 ID + IP + 端口 + 指纹 + 配对码）
  → 启动 TCP 监听 9527 端口
  → 注册 mDNS 服务 _xiaopacai._tcp.local.
  → 启动 UDP 广播（端口 9528）

步骤2: 儿童端发现
  → 启动 mDNS 查询 _xiaopacai._tcp.local.
  → 监听 UDP 广播端口 9528
  → 10 秒内应在设备列表看到家长端
  → 预期：发现方式 = "mdns" 或 "udp"
  ✓ 验证点：设备列表显示家长端名称与 IP

步骤3: 儿童端配对
  → 扫描家长端二维码 或输入 6 位配对码
  → 点击"连接"
  ✓ 验证点：连接状态从 CONNECTING → HANDSHAKING → CONNECTED

步骤4: TLS 握手 + 证书指纹校验
  → TCP 连接建立
  → TLS 1.3 握手完成
  → 儿童端计算家长端证书 SHA-256 指纹
  → 首次配对：记录指纹
  → 后续连接：比对已保存的指纹
  ✓ 验证点：日志显示 "证书指纹校验通过"
  ✓ 验证点：connectedFingerprint 已更新

步骤5: 应用层握手
  → 儿童端发送 handshake 消息（含设备信息）
  → 家长端收到并回复确认
  ✓ 验证点：双方日志显示 handshake 成功
```

### 场景 B：正常数据交换

```
步骤1: 儿童端上报使用数据
  → 发送 usage_report 消息
  → 包含当日各应用使用时长
  ✓ 验证点：家长端数据库 usage_records 表有新增记录

步骤2: 家长端下发策略
  → 修改每日限额从 60 分钟改为 120 分钟
  → 发送 policy_sync 消息
  → 儿童端接收并发送 policy_ack
  ✓ 验证点：儿童端 policy_cache 表更新
  ✓ 验证点：UI 显示新的限额

步骤3: 心跳维持
  → 儿童端每 30 秒发送 heartbeat
  → 家长端回复 heartbeat_ack
  ✓ 验证点：heartbeatMissCount = 0
```

### 场景 C：断开 → 重连

```
步骤1: 模拟断开
  → 关闭家长端（Ctrl+C）或切断网络
  → 儿童端心跳超时（3 次无响应 = 90 秒）
  ✓ 验证点：连接状态变为 DISCONNECTED

步骤2: 自动重连
  → 重新启动家长端
  → 儿童端自动尝试重连（指数退避: 1s, 2s, 4s, 8s...）
  ✓ 验证点：连接状态变为 RECONNECTING
  ✓ 验证点：最终恢复 CONNECTED

步骤3: 数据重传
  → 儿童端查询 sync_status=0 的记录
  → 增量推送到家长端
  ✓ 验证点：家长端断网期间的数据在重连后补齐
```

### 场景 D：手动 IP 兜底

```
前提：mDNS 和 UDP 广播均不可用

步骤1: 儿童端手动输入
  → 进入"手动连接"界面
  → 输入家长端 IP:192.168.1.100:9527

步骤2: 配对验证
  → 输入 6 位配对码确认身份
  ✓ 验证点：discoveryMethod = "manual"
```

### 场景 E：安全验证

```
测试1: 中间人防护
  → 使用不同的自签名证书模拟中间人
  ✓ 验证点：儿童端日志 "证书指纹不匹配，连接拒绝"
  ✓ 验证点：连接状态保持 DISCONNECTED

测试2: 配对码过期
  → 生成配对码后等待 11 分钟
  → 尝试用已过期的配对码连接
  ✓ 验证点：家长端拒绝连接

测试3: 传输加密
  → 使用 Wireshark 抓包
  ✓ 验证点：TCP payload 全部为加密数据
  ✓ 验证点：无法直接读取 JSON 消息
```
