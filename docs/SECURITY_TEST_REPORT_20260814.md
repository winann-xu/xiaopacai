## 八、升级影响与迁移通知（须随发布同步告知）

1. **Windows 家长端升级（d14dacf）**：
   - 旧明文密钥库数据自动迁移到 DPAPI 新库（迁移失败保留原文件，不丢数据）；
   - 旧库中已配设备没有指纹记录 → **儿童端首次重连需用家长端「设置→设备配对」生成的配对码重新配对一次**；
   - 家长端证书保持原证书（迁移不改指纹），儿童端保存的家长端指纹仍有效。
2. **Web K5 会话迁移（6d89287）**：浏览器用户旧 localStorage token 不再被识别 → **需重新登录**（此后走 httpOnly Cookie）。
3. **Android 默认家长密码删除（2850314）**：家长须在家长模式中显式设置密码后才能使用受保护功能；测试设备上伪造/过期指纹的儿童端需重新配对。
4. **恢复备份场景**：恢复 Web/Android/Windows 任一备份后，P2P 指纹链可能断裂，需按配对流程重新配对。
5. **协议变更**：P2P 握手新增服务端指纹校验（扫码/中继注册响应已携带），Web 服务端与 Android 客户端必须同版本发布（预发布已同步）。
