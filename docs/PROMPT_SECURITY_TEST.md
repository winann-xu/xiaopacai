# 小趴菜 · 公网部署安全测试提示词（V1.0）

> 用法：把本提示词整体交给 Codex / Claude 或安全测试人员执行；或作为验收清单人工执行。
> 前置条件：使用与生产一致的预发布环境（数据为脱敏副本），所有测试已获授权；
> 每条用例必须记录证据（请求/响应/日志/截图），不得影响真实用户数据。

---

## 一、角色与目标

你是资深安全测试工程师，正在验收一套将部署到公网的儿童守护系统（Web + P2P 中继 + Android + Windows）。
你的唯一验收标准是：[docs/SECURITY_BASELINE.md](SECURITY_BASELINE.md) 中的红线逐条合规、高危漏洞清零。
测试风格：不找最短路径；模拟真实攻击链（信息收集 → 突破认证 → 横向越权 → 提权 → 数据窃取/破坏 → 持久化）。

## 二、测试资产与暴露面盘点

1. 列出全部入口：Web 页面/API、静态下载、登录/扫码/重置、P2P 9527、中继、诊断上报、公告推送、策略下发。
2. 用 OWASP Top 10 2021 建立风险矩阵，标注每项涉及的红线编号（R1.1…R11.2）。
3. 先做“已知风险复测清单”（见第九节）——这些都是预审发现的问题，必须验证是否已修复。

## 三、Web / API 安全测试

### 3.1 认证与会话
- 未带 token 访问每个业务接口 → 必须 401/403，禁止 200 或 SPA 兜底 200。
- 过期/伪造/篡改 JWT → 拒绝；refresh token 重放/吊销 → 拒绝；退出后 token 失效。
- 弱口令、默认口令（admin/admin123）、密码哈希算法与盐、登录错误信息不泄露账号是否存在。
- 登录/扫码 ticket/重置密码：限流、退避、一次性、过期、绑定客户端。

### 3.2 越权（重点）
- 用家长 A 的 token 访问家长 B 的设备/策略/报告/公告/诊断 → 必须拒绝（水平越权）。
- 普通 parent 调用 admin 接口 → 必须 403；改角色/越权提权 → 拒绝并审计。
- 解绑/重绑/扫码绑定流程：能否把他人设备绑到自己账号？解绑后数据是否残留可读？

### 3.3 注入与输入
- SQL 注入：所有带参数接口（deviceId、日期、搜索、导出）输入 `' OR 1=1--`、时间盲注等。
- XSS：公告标题/内容、设备名、策略标签等回显点注入 `<script>`/事件属性；CSP 是否生效。
- 命令注入：导出文件名、诊断字段等不可到达 shell。
- 参数校验：时间必须 `HH:mm`（回归 2026-08-14 就寝时间存成 ISO 的同类问题）、数值越界（限额 30-480）、包名格式。
- 请求体大小/超长字段 → 4xx，不崩溃。

### 3.4 敏感信息泄露
- 响应头、错误页、Swagger（生产必须关闭）、静态目录遍历、.git/.env/备份文件可访问性。
- API 响应不得泄露他人数据、密码哈希、令牌、内网路径、堆栈细节。
- 下载中心：未授权可下载安装包（允许），但不得泄露目录列表或其它文件。

### 3.5 CSRF / CORS / 会话固定
- 修改类请求是否校验 Origin/CSRF；CORS 生产是否收紧（禁止 `*`+Credentials）。
- 浏览器本地存储中的 token 可被 XSS 窃取 → 评估是否已迁移 httpOnly Cookie。

## 四、P2P / 中继安全测试（本项目特有，重点）

### 4.1 TLS 身份校验
- 中间人：自签证书/伪造证书连接 9527 → 必须被拒绝（**当前服务端接受任意客户端证书，属已知违反项**）。
- 服务端证书指纹固定：客户端换服务器后是否提示“指纹不匹配”而非静默连接。

### 4.2 配对与认证
- 6 位配对码：连续暴力（≥1000 次/分钟）→ 必须限流/锁定/审计；过期配对码必须失效。
- 伪造 deviceId 连接（枚举/复用他人 deviceId）→ 必须被拒或无法接收他人数据。
- 握手后无鉴权直发消息（usage_report/announcement_ack/heartbeat）→ 必须校验会话归属。

### 4.3 中继越权与数据泄露
- 儿童 A 的上报是否可能被家长 B 收到；中继路由是否严格按 owner 绑定。
- 消息注入：向中继伪造 usage_report/诊断/公告回执，是否影响其它账号。
- 放大攻击：大量小消息是否可导致服务器内存/带宽耗尽（连接数、帧长、频率限制）。

### 4.4 会话生命周期
- 断线重连是否会替换/复用他人会话；心跳超时是否回收；重复会话是否互踢且鉴权。

## 五、Android / Windows 客户端安全

- 本地数据库是否加密（SQLCipher）、密钥是否 KeyStore、备份/导出是否泄露。
- 日志是否包含 token/密钥/隐私；错误提示是否泄露内部路径。
- 证书固定与 P2P 指纹校验是否真实生效（换服务器/中间人场景）。
- 权限最小化：仅申请必要权限；无障碍/用量权限被撤销时的检测与告警是否有效。
- 客户端是否可被注入/篡改（调试开关、硬编码密钥、可逆混淆）——公网版应加固。

## 六、数据与隐私合规

- 服务器数据库：是否存在明文密码/令牌/密钥；库文件是否加密；备份是否加密。
- 数据最小化：服务器实际存储字段是否超出“账号/互联/诊断/报告”所需；儿童使用明细是否最小化。
- 注销/解绑：账号删除后，设备、策略、报告、诊断、中继会话是否级联清理；备份中的残留如何处理。
- 导出：报告/审计导出是否鉴权+脱敏+审计；导出文件是否含他人数据。

## 七、部署与运维加固

- HTTPS：公网访问是否强制 TLS 1.2+、HSTS；HTTP 是否跳转或拒绝；证书链是否有效。
- 端口：公网仅暴露必要端口；P2P 端口是否需公网直开或走网关控制。
- 默认口令：admin/admin123 是否强制改密；生产 JWT/DB 密钥是否在环境变量/密钥管理而非明文配置。
- 服务运行：非 root、最小权限、NoNewPrivileges、文件权限（密钥 0600）。
- 安全响应头：X-Frame-Options、CSP、nosniff、Referrer-Policy。
- 监控告警：异常登录、异常流量、P2P 异常会话、审计日志告警是否配置。

## 八、回归与验收输出

1. 每条用例输出：编号｜风险等级(P0/P1/P2)｜测试步骤｜预期｜实际｜证据｜结论。
2. 输出《安全验收报告》：红线合规勾选表（R1.1–R11.2 逐条）、漏洞清单与修复状态、残余风险清单。
3. 验收门槛：**P0/P1 清零、红线零违反**才允许公网上线；P2 须给出限期计划。

## 九、已知风险复测清单（预审发现，必须逐项验证）

| 编号 | 已知问题 | 预期修复后行为 |
|---|---|---|
| K1 | P2P 服务端接受任意客户端证书（`userCertificateValidationCallback => true`） | 拒绝未授权证书/无指纹客户端 |
| K2 | 策略/报告等接口缺少设备归属校验（家长可操作他人设备） | 越权访问一律 403 |
| K3 | 登录/配对码/扫码无限流，6 位配对码可爆破 | 限流+退避+审计+过期 |
| K4 | 生产 JWT/DB 密钥在明文 appsettings 配置 | 密钥走环境变量/密钥管理，配置文件不含真实密钥 |
| K5 | 前端 token 存 localStorage | 迁移 httpOnly Cookie 或等效防护 |
| K6 | 生产无 HTTPS | 强制 TLS 1.2+ / HSTS |
| K7 | 就寝时间曾存成 ISO 时间戳（输入校验缺失） | 全站输入白名单校验回归 |
| K8 | 下载中心/静态资源暴露面 | 仅允许预期文件，无目录遍历 |
| K9 | 诊断数据最小化与去标识化 | 字段收敛、无越权读取 |
| K10 | 审计日志覆盖与防篡改 | 安全事件全覆盖、追加式存储 |
