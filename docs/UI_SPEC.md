# 小趴菜 UI 设计规范 v1.0

> [TASK-D1-05] 本文档定义小趴菜两端（家长端 WPF + 儿童端 Android Compose）统一的 UI 设计规范。

## 一、设计理念

- **温暖可信**：以绿色为主色调，传达安全、守护、成长的感觉
- **简洁高效**：信息密度适中，家长快速掌握儿童使用情况
- **儿童友好**：儿童端界面圆角、柔和色彩，避免说教感
- **全中文界面**：所有文案、标签、提示使用中文

## 二、色板

### 主色调：守护绿

| 名称 | 色值 | 用途 |
|------|------|------|
| 主色 | `#4CAF50` | 按钮、选中态、主要交互 |
| 主色深 | `#2E7D32` | 导航栏、强调区域 |
| 主色浅 | `#C8E6C9` | 卡片背景、次要容器 |
| 主色容器 | `#E8F5E9` | 大背景区域 |

### 功能色

| 名称 | 色值 | 用途 |
|------|------|------|
| 警告橙 | `#FF9800` | 临近限额、连接中 |
| 危险红 | `#E53935` | 超时停用、错误状态 |
| 信息蓝 | `#2196F3` | 公告、提示信息 |
| 中性灰 | `#9E9E9E` | 未连接、禁用态、辅助文字 |

### 深色模式色板

| 名称 | 浅色值 | 深色值 |
|------|--------|--------|
| 背景 | `#F5F5F5` | `#121212` |
| 表面 | `#FFFFFF` | `#1E1E1E` |
| 主文字 | `#212121` | `#E0E0E0` |
| 辅文字 | `#757575` | `#9E9E9E` |

## 三、字体与排版

### 儿童端 (Android)

| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| H1 大标题 | 28sp | Bold | 36sp | 页面主标题 |
| H2 中标题 | 22sp | SemiBold | 28sp | 卡片标题 |
| H3 小标题 | 16sp | Medium | 24sp | 列表项标题 |
| Body 正文 | 14sp | Normal | 20sp | 正文段落 |
| Caption | 12sp | Normal | 16sp | 辅助说明 |
| 数字大 | 56sp | Bold | — | 剩余时长等关键数字 |

### 家长端 (Windows)

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 页面标题 | 24px | Bold | 各页面标题 |
| 卡片标题 | 18px | SemiBold | 摘要卡片数字 |
| 正文 | 14px | Normal | 列表与详情 |
| 小字 | 12px | Normal | 辅助说明 |

## 四、间距系统（8px 基准）

| Token | 值 | 用途 |
|-------|-----|------|
| xs | 4dp/px | 紧密元素间距 |
| sm | 8dp/px | 相关元素间距 |
| md | 12dp/px | 卡片内边距 |
| lg | 16dp/px | 卡片间距、页面边距 |
| xl | 24dp/px | 区块间距、页面内边距 |
| 2xl | 32dp/px | 大区块分隔 |

## 五、组件规范

### 5.1 卡片 (Card)

- 圆角：12dp（儿童端）/ 8px（家长端）
- 阴影：轻微（Elevation 2dp / DropShadow BlurRadius 8）
- 内边距：16dp/px
- 间距：12dp/px（卡片间）

### 5.2 按钮

| 类型 | 样式 |
|------|------|
| 主按钮 | 填充主色，白色文字，圆角 12dp |
| 次按钮 | 描边主色，主色文字，圆角 12dp |
| 文字按钮 | 无边框，主色文字 |
| 危险按钮 | 填充危险红，白色文字 |

### 5.3 进度条

- 高度：8dp/px
- 圆角：4dp/px
- 颜色：主色（正常）→ 警告橙（80%+）→ 危险红（100%）

### 5.4 状态指示器

- **在线/已连接**：绿色圆点 `#4CAF50` 8dp
- **警告/连接中**：橙色圆点 `#FF9800` 8dp
- **离线/未连接**：灰色圆点 `#9E9E9E` 8dp
- **超时停用**：红色圆点 `#E53935` 8dp

## 六、状态设计

### 6.1 空态

- 居中图标 + 说明文字 + 引导按钮
- 文字颜色 `#9E9E9E`
- 示例文案："暂无已连接的儿童设备，点击下方按钮添加"

### 6.2 加载态

- 居中 CircularProgressIndicator（儿童端）/ ProgressRing（家长端）
- 下方 "加载中..." 文字（12sp, 辅助色）

### 6.3 错误态

- 居中错误图标（橙色感叹号）
- 错误消息文字（14sp）
- "重试"按钮

### 6.4 超时停用态

- 儿童端：全屏红色/橙色背景卡片
- 家长端：设备列表标记红色标签"已停用"

## 七、深色模式

- 两端均支持跟随系统深色模式
- 儿童端：通过 Material3 darkColorScheme 自动切换
- 家长端：MaterialDesignThemes 提供 Dark 主题切换
- 关键色值在深色模式下提亮（如主色 `#4CAF50` → `#81C784`）

## 八、无障碍要求

- 所有可点击元素最小触摸区域：48dp × 48dp
- 文字与背景对比度 >= 4.5:1（正文）/ >= 3:1（大标题）
- 图标配 contentDescription（Android）/ AutomationProperties.Name（Windows）
- 支持系统字体缩放（Android sp 单位，Windows 相对字号）
- 焦点顺序符合视觉布局

## 九、动画

| 动画 | 时长 | 用途 |
|------|------|------|
| 页面切换 | 300ms | 导航切换淡入淡出 |
| 状态变化 | 200ms | 连接状态颜色切换 |
| 进度更新 | 500ms | 使用时长进度条动画 |
| 加载指示 | 循环 | 数据加载中旋转 |

## 十、文案规范

- 全中文界面，不使用英文缩略语（除非行业内通用如"Wi-Fi"）
- 儿童端文案温暖、鼓励："你已经用了 X 分钟，休息一下吧～"
- 家长端文案清晰、客观："今日总使用 120 分钟，超出限额 20 分钟"
- 错误提示给出明确操作建议而非仅报错误码
- 超时停用说明必须包含能力边界描述
