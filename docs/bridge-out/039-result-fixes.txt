二、详细修复说明
============================================================

【BUG-0810-05】SavePolicy 参数清空
  文件: windows/XiaopacaiParent/Services/PolicyEngineService.cs

  问题: SavePolicy() 先执行 SELECT 查询（带 @type/@deviceId 参数），
        然后复用同一 SqliteCommand 执行 UPDATE/INSERT。INSERT 路径
        试图再次 AddWithValue("@type"...)，抛出 ArgumentException
        "Parameter already exists in the collection"。

  修复: 在 SELECT 的 ExecuteScalar() 之后添加 cmd.Parameters.Clear()，
        确保后续 INSERT/UPDATE 路径的语句参数从干净状态开始。

  影响: 首次调用 SavePolicy 创建新策略时必现崩溃，所有策略类型均受影响。
        修复后 CreateDefaultPolicies → SavePolicy(INSERT) 正常执行。


【BUG-0810-06】ReportView using/CryptoService using System.IO/AvgDailySubText
  涉及文件:
    - windows/XiaopacaiParent/Services/CryptoService.cs
    - windows/XiaopacaiParent/Views/ReportView.xaml.cs
    - windows/XiaopacaiParent/Views/ReportView.xaml

  修复内容:
    1. CryptoService.cs: 添加 using System.IO;
       File.Exists(dbPath) 和 File.OpenRead(dbPath) 在 ValidateDatabaseIntegrity()
       中未导入 System.IO 命名空间 → 编译错误 CS0103。
    2. ReportView.xaml.cs: 添加 using System.Diagnostics; using System.IO;
       using System.Text; → 替换全限定名:
         System.Diagnostics.Debug.WriteLine → Debug.WriteLine
         System.IO.File.WriteAllText → File.WriteAllText
         new System.Text.StringBuilder() → new StringBuilder()
    3. ReportView.xaml: 为「日均使用」卡片副标题 TextBlock 添加
       x:Name="AvgDailySubText"。代码后端 OnRenderSummaryCards() 中
       AvgDailySubText.Text = "..." 在运行时抛出 NullReferenceException，
       因 XAML 未定义该名称。

  影响: CryptoService 编译失败 + ReportView 运行时崩溃，报告功能完全不可用。


【BUG-0810-07】分类限额策略键加入 category + 补测试
  文件:
    - windows/XiaopacaiParent/Services/PolicyEngineService.cs
    - tests/XiaopacaiParent.Tests/XiaopacaiParent.Tests.csproj (新建)
    - tests/XiaopacaiParent.Tests/PolicyEngineServiceTests.cs (新建)

  问题: SavePolicy/GetPolicy/DeactivatePolicy 的 UPSERT 键仅为
        (policy_type, device_id)，不区分 category。如保存 game 分类
        限额后再保存 social 分类，后者会覆盖前者（同 policy_type）。

  修复:
    1. SavePolicy: SELECT 查重查询新增 json_extract(policy_data,
       '$.category') = @category OR @category = '' 条件，确保
       空 category 的策略（非分类类型）不受影响。
    2. GetPolicy: 新增可选 category 参数，支持按分类精确查询。
    3. DeactivatePolicy: 新增可选 category 参数，支持按分类精确停用。

  测试: 创建 xunit 测试项目 (tests/XiaopacaiParent.Tests/)，10 个测试:
    - SavePolicy_NewPolicy_ShouldCreate
    - SavePolicy_ExistingPolicy_ShouldUpdate
    - SavePolicy_CategoryLimitDifferentCategories_ShouldNotOverwrite ⬅ 核心
    - SavePolicy_CategoryLimitSameCategory_ShouldUpdate
    - GetPolicy_WithCategory_ShouldReturnCorrectPolicy
    - GetPolicy_WithoutCategory_ShouldReturnAnyCategoryLimit
    - SavePolicy_NonCategoryPolicies_ShouldStillWork
    - CreateDefaultPolicies_ShouldCreateAllDefaults
    - CreateDefaultPolicies_Idempotent_ShouldNotDuplicate
    - DeactivatePolicy_ShouldSoftDelete
    - DeactivatePolicy_CategoryLimit_ShouldTargetCorrectCategory

  运行方式 (Windows):
    dotnet test tests/XiaopacaiParent.Tests/XiaopacaiParent.Tests.csproj
