二、核心功能实现
============================================================

1. 时长统计 (D2-01)
   - UsageStatsCollector: 5分钟定时采集循环
   - UsageRecordDao: 加密数据库CRUD + 未同步标记
   - 应用分类引擎: 游戏/社交/视频/学习/其他（40+关键词规则）
   - 超时状态实时检测 + UI 30秒轮询刷新

2. 策略引擎 (D2-02)
   - 5种策略: daily_limit/sleep_time/whitelist/blacklist/category_limit
   - PolicyConfig JSON序列化 + 版本管理
   - WPF配置UI: 滑块限额 + 时段选择 + 黑/白名单模板
   - 默认预设: 2h日限额 + 21:00-7:00就寝 + 游戏1h + 社交1.5h

3. 应用拦截 (D2-03)
   - AppInterceptor: 4级优先级判断(黑名单 > 超时 > 分类限额 > 白名单)
   - 系统应用(phone/contacts/mms等)永不拦截
   - GuardianAccessibilityService: 窗口切换监听 + 3秒防抖
   - BlockOverlayActivity: 品牌红全屏锁定 + 返回桌面 + 紧急电话

4. 公告 (D2-04)
   - Windows: AnnouncementService CRUD + AnnouncementView 管理界面
   - Android: AnnouncementDao + 守护主页实时加载
   - 3级优先级: 普通(蓝)/重要(橙)/紧急(红)

5. 同步协议 (D2-05)
   - 上行(儿童→家长): usage_report 增量同步(200条/次)
   - 下行(家长→儿童): policy_update + announcement_push
   - SyncManager: 5分钟定时同步 + 断网缓存补发
   - P2PListenerService: JSON消息路由(usage_report/handshake/heartbeat)

6. 超时停用 (D2-06)
   - TimeoutExecutor: 状态监测 + 主动封锁 + 事件记录
   - Full模式: 立即启动BlockOverlayActivity
   - 历史查询: getRecentTimeoutEvents(最近7天)
   - 完整流程: 采集→检查→封锁→拦截→覆盖界面
