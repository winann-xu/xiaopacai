## 一、P1 已实现清单

### 1. RoleManager（./role/RoleManager.kt）
- 角色枚举：UNSET / CHILD / PARENT
- getCurrentRole() / setCurrentRole()
- isFirstLaunch() 首次启动检测
- switchToParent(password) / switchToChild(password) — 均需 PBKDF2 密码校验
- setParentPassword / changeParentPassword / verifyParentPassword / isValidPasswordFormat
- 角色持久化到 SharedPreferences (xiaopacai_role_prefs)
- 密码复用现有 ParentPasswordManager（PBKDF2-SHA256, 10万次迭代）

### 2. MainActivity 角色分流
- when 分支：UNSET → RoleGuideScreen / PARENT → ParentLoginScreen 或 ParentHomeScreen / CHILD → MainScreen
- 首次启动：选择角色（"我是家长"/"我是孩子"）
- 儿童端：免密直进守护主页，底部增加"切换到家长端"入口→触发登录
- 家长端：密码登录（先判断 isPasswordSet，未设则引导设置密码）
- 退出机制：登录页"返回儿童端"（无需密码的逃生通道）；家长主页切回儿童需密码

### 3. ParentP2PListenerService（./p2p/ParentP2PListenerService.kt）
- Android 前台服务（START_STICKY），通知渠道 channel_parent_p2p
- TCP 监听端口 9527（ServerSocket, reuseAddress）
- TLS 1.3/1.2：EC P-256 自签名证书，Android KeyStore 持久化（别名 xiaopacai_p2p_server）
- 证书 10 年有效期，指纹(SHA-256)重启稳定不变
- 4 字节大端长度前缀 + JSON 帧协议（与儿童端 P2PConnectionService 完全兼容）
- 消息处理：
  - handshake → 配对码校验（如启用）+ 设备注册/持久化 → 响应 policy_update
  - usage_report → 写 parent_usage_summary 表 → 响应 sync_ack
  - heartbeat → 响应 heartbeat_ack
- 6 位配对码：generatePairingCode() + verifyPairingCode()
  - 5 分钟有效期，5 次限次/失败后锁定 5 分钟，一次性使用
- 并发设备连接：ConcurrentHashMap + 每连接独立协程
- 密钥套件过滤（TLS_AES/TLS_CHACHA/ECDHE+AES+GCM）

### 4. AppDatabase V2 扩展
- DATABASE_VERSION: 1 → 2
- 新增 4 张家长端表（IF NOT EXISTS，兼容 fresh install + upgrade）：

  - parent_policies：policy_id/policy_type/policy_data/version/target_device_id/is_active
  - parent_announcements：announcement_id/title/content/priority/status/valid_from/valid_until

- onUpgrade V1→V2 迁移逻辑
- 各表加索引（is_active、policy_type、status、device_id+date）
