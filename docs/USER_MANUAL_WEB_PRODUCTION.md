# 小趴菜 Web 3.0 生产环境用户手册

版本：3.0.0-p2（生产）    部署日期：2026-08-12    服务器：192.168.50.11（Ubuntu 20.04）
访问地址：http://192.168.50.11:5000

## 一、登录

- 打开浏览器访问 `http://192.168.50.11:5000`
- 默认管理员账号：`admin` / `admin123`（**登录后请立即在“设置 → 修改密码”中更换**）
- 登录页同时支持“扫码登录”（家长端 APP 授权）与“忘记密码”（恢复码/扫码重置）

## 二、界面总览

### 家长端（普通用户，登录后默认）
- **仪表盘**：设备在线数、今日使用、超时停用数、公告状态、快捷操作
- **设备管理**：儿童设备列表/在线状态、解绑、应用分类（查看/修改并下发）
- **策略配置**：每日限额、就寝时段、分类限额、黑白名单；保存后下发儿童端
- **公告管理**：新建/编辑/发布/撤回/删除公告（普通/重要/紧急优先级）
- **使用报告**：今日/7天/30天使用时长、分类占比
- **设置**：修改密码、账号信息、退出登录

### 管理端（管理员，登录后菜单含）
- **账号管理**：用户列表、重置密码、角色管理
- **设备管理（管理）**：全部设备、强制解绑、设备令牌
- **审计日志**：登录/配对/策略/公告等操作记录
- **系统配置**：限速、安全参数等
- **数据管理**：诊断数据、中继会话
- **故障诊断**：按设备/时间查看儿童端诊断上报、统计常见异常、导出
- **中继会话**：查看在线中继设备（parent/child）

## 三、与手机端/电脑端联动

### 1. 儿童端连接 Web（跨网/中继）
- 儿童端 App → “连接家长端” → 手动连接：IP 填 `192.168.50.11`，端口 `9527`，配对码用 Web 管理员在“设备管理”生成的 6 位码
- 儿童端先在本机完成配对注册，之后可在任意网络（WiFi/蜂窝）持续上报

### 2. 家长端（Android）连接 Web 中继
- 家长端 App → 设置 → Web 云端中继：Web 地址 `192.168.50.11`、端口 `5000`
- “Web 账号”登录（admin/新密码）→ 连接中继
- 之后儿童端经 Web 上报的数据会实时转发到家长端 App

### 3. 家长端（Windows 电脑）
- 运行 Windows 家长端 → 儿童端手动连接填电脑 IP + 配对码（局域网直连，不经过 Web）

## 四、核心功能操作

### 策略下发
1. 策略配置 → 修改限额/时段/黑白名单 → 保存
2. 儿童端在线时自动收到 policy_update（可在儿童端“设置”中核对）
3. 超时后按“超时处理方式”（整机停用/部分停用/仅提醒）执行

### 公告推送
1. 公告管理 → 新建公告 → 填标题/正文/优先级 → 保存（草稿）
2. 点“发布”→ 在线儿童端立即收到（普通=通知直达，紧急=全屏置顶+确认回执）
3. 已发布公告可“撤回”；撤回后编辑保存回草稿，可再次发布

### 应用分类
1. 设备管理 → 目标设备 → 应用分类 → 修改分类（game/social/video/learning/other）
2. 保存后随策略推送到儿童端，用于分类限额与部分停用

### 诊断上报
- 儿童端每日自动上报诊断（权限/服务/崩溃/网络/数据库大小等）
- 管理端“故障诊断”可筛选、查看、导出

### 扫码登录（家长 APP 授权 Web）
1. Web 登录页 → 扫码登录 → 显示二维码（90 秒有效）
2. 家长端 App → 设置 → 扫码登录 Web → 扫码确认
3. Web 自动登录（免注册新账号）

### 忘记密码
1. 登录页 → 忘记密码 → 生成 reset-ticket 二维码（10 分钟有效）
2. 家长端 App 扫码确认身份 → 网页设置新密码
3. 或使用首次设置家长账号时生成的 8 位恢复码直接重置

- 服务管理：
  - 状态：`systemctl status xiaopacai-web`
  - 启动/停止/重启：`systemctl start|stop|restart xiaopacai-web`
  - 开机自启：已启用
- 部署目录：`/home/winann/xiaopacai-web`（dotnet 运行时在 `~/.dotnet`）
- 数据目录：`/home/winann/xiaopacai-web/Data/`

- 端口：5000（Web/API）、9527（P2P TLS）
- 升级部署：停服务 → 覆盖 `/home/winann/xiaopacai-web`（保留 Data）→ 起服务

## 六、安全注意事项
1. 立即修改默认管理员密码
2. 生产 JWT 密钥已随机生成（`appsettings.Production.json`），请勿外泄
3. 儿童端上报数据含应用使用明细，仅用于监护用途
4. 如需公网部署，请置于反向代理（Nginx）后并启用 HTTPS

## 七、常见问题
- **页面打不开**：确认服务 active、5000 端口可达（`ss -tlnp | grep 5000`）
- **儿童端连不上 9527**：确认防火墙放行 9527（`sudo ufw allow 9527/tcp`）
- **数据库异常**：停止服务后备份并删除 `Data/xiaopacai.db` 重启（将重建并恢复 admin/admin123）
- **儿童端收不到公告**：确认设备在线（设备管理显示 online）
