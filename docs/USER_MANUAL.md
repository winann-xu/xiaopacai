## 1. 系统概述

小趴菜是一套亲子设备使用守护系统，由 **Windows 家长端** 和 **Android 儿童端** 组成。家长通过 Windows 应用配置设备使用规则，儿童 Android 设备自动执行限制策略。

### 核心功能

| 功能 | 说明 |
|------|------|
| 时长统计 | 自动采集儿童端各应用使用时长，精确到分钟 |
| 策略引擎 | 支持每日限额、就寝时段、应用黑白名单、分类限制 |
| 应用拦截 | 超时/违规时自动全屏封锁，仅允许白名单应用 |
| 公告推送 | 家长端发送公告，儿童端即时显示 |
| 数据报告 | 日报/周报，支持 TXT/JSON 导出 |
| 安全防护 | 防卸载、防绕过、加密数据库、密码保护 |

## 3. 快速开始

### 3.1 家长端安装（Windows）

1. 安装 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)
2. 从发布包中解压 `XiaopacaiParent` 文件夹
3. 双击运行 `XiaopacaiParent.exe`
4. 首次运行需允许防火墙访问（用于 P2P 通信）

### 3.2 儿童端安装（Android）

1. 将 `app-debug.apk` 传输到儿童设备
2. 在设备「设置 → 安全」中启用「未知来源」安装
3. 安装 APK
4. 首次启动按向导授予以下权限：
   - **使用情况访问**：设置 → 安全 → 使用情况访问权限 → 小趴菜
   - **无障碍服务**：设置 → 无障碍 → 已安装的服务 → 小趴菜守护
   - **设备管理器**：设置 → 安全 → 设备管理器 → 小趴菜设备管理

### 3.3 配对连接

详见 [第 6 节：配对与连接](#6-配对与连接)。

## 4. 家长端操作指南（Windows）

### 4.1 主界面概览

启动后进入仪表盘主界面，包含：

- **设备列表**：显示已配对的儿童设备及在线状态
- **今日概览**：儿童设备当日使用时长、应用排行
- **策略摘要**：当前启用的策略列表
- **公告管理**：已发送的公告及阅读状态

### 4.2 配置策略

1. 点击左侧导航「策略配置」
2. 选择策略类型：
   - **每日限额**：设置每日总使用时长上限（分钟）
   - **就寝时段**：设置禁止使用的起止时间
   - **白名单**：添加始终允许的应用包名
   - **黑名单**：添加始终禁止的应用包名
   - **分类限制**：按应用分类（游戏/社交/视频/学习/其他）设置限额
3. 填写参数后点击「保存」
4. 策略自动同步到已配对的儿童设备

### 4.3 发布公告

1. 点击左侧导航「公告管理」
2. 点击「新建公告」
3. 填写标题、正文、优先级（普通/重要/紧急）
4. 选择目标设备（全部/指定设备）
5. 设置过期时间（可选）
6. 点击「发送」

### 4.4 查看报告

1. 点击左侧导航「使用报告」
2. 选择时间范围（今日/本周/自定义）
3. 查看可视化图表：
   - 使用时长趋势图
   - 应用分类占比饼图
   - 日均使用统计卡片
4. 点击「导出」可选择 TXT 或 JSON 格式

### 4.5 设置

1. 点击右上角齿轮图标进入「设置」
2. 可配置项：
   - **家长密码**：修改密码（默认 000000）
   - **同步间隔**：数据同步频率（默认 5 分钟）
   - **数据保留**：本地记录保留天数
   - **数据库路径**：加密数据库存储位置

## 5. 儿童端操作指南（Android）

### 5.1 主界面

儿童端启动后显示守护主界面：

- **剩余时长**：今日剩余可用时长（环形进度条）
- **公告栏**：家长推送的最新公告
- **连接状态**：与家长端的连接状态指示
- **应用统计**：今日各应用使用时长排名

### 5.2 权限管理

所有三项权限必须在首次启动时授予，否则守护功能无法正常工作：

| 权限 | 用途 | 不授予的影响 |
|------|------|-------------|
| 使用情况访问 | 采集应用使用时长数据 | 无法统计使用时长，策略不生效 |
| 无障碍服务 | 检测前台应用切换，触发拦截 | 无法实时拦截被禁应用 |
| 设备管理器 | 防止卸载应用、禁用守护 | 儿童可自行卸载或停用守护 |

### 5.3 家长密码验证

当需要修改设置、退出守护模式或执行敏感操作时，需输入家长密码：

- **默认密码**：`000000`
- **防止暴力破解**：连续 5 次错误后锁定 5 分钟
- **修改密码**：在家长端「设置」中修改，同步后生效

### 5.4 超时封锁

- 达到每日限额后，设备自动进入封锁模式
- 全屏封锁界面显示剩余锁定时间
- 仅白名单应用（系统拨号、设置等）可用
- 次日自动解除或家长端远程解除

## 6. 配对与连接

### 6.1 配对流程

1. 确保 Windows 家长端和 Android 儿童端连接同一 Wi-Fi
2. 在家长端点击「添加设备」
3. 家长端显示二维码（含设备信息和配对令牌）
4. 在儿童端点击「扫码配对」，扫描家长端二维码
5. 双方确认配对请求
6. 配对成功后，后续自动连接

### 6.2 连接状态

| 状态图标 | 含义 |
|----------|------|
| 🟢 绿色 | 已连接，数据正常同步 |
| 🟡 黄色 | 正在连接中 |
| 🔴 红色 | 未连接（检查网络和防火墙） |
| ⚪ 灰色 | 设备离线 |

### 6.3 网络要求

- 双方必须在同一局域网（同一路由器下）
- 防火墙需允许以下端口：
  - TCP 9527：P2P 控制通道
  - TCP 9528：P2P 数据通道
  - UDP 5353：mDNS 服务发现
- 支持断网缓存：离线期间数据暂存本地，恢复后自动补传

## 7. 策略配置说明

### 7.1 策略类型详解

#### 每日限额（daily_limit）
- **参数**：`limitMinutes` — 每日总使用时长上限
- **行为**：达到上限后进入 full 模式全机封锁
- **解除**：次日 00:00 自动重置

#### 就寝时段（sleep_time）
- **参数**：`sleepStart` / `sleepEnd` — 起止时间（HH:mm）
- **行为**：时段内所有非白名单应用被拦截
- **注意**：支持跨日时段（如 21:00—07:00）

#### 白名单（whitelist）
- **参数**：`packageNames` — 始终允许的应用包名列表
- **行为**：白名单应用不受任何策略限制
- **建议**：至少包含系统拨号和设置应用

#### 黑名单（blacklist）
- **参数**：`packageNames` — 始终禁止的应用包名列表
- **行为**：黑名单应用在任何时间都被拦截

#### 分类限制（category_limit）
- **参数**：`category` + `categoryLimitMinutes`
- **支持分类**：`game`（游戏）/ `social`（社交）/ `video`（视频）/ `study`（学习）/ `other`（其他）
- **行为**：该分类应用总计使用时长达到上限后拦截

### 7.2 策略优先级

```
设备管理器锁定 > 黑名单 > 就寝时段 > 分类限制 > 每日限额 > 白名单
```

- 白名单优先级最低：其他策略限制后白名单应用仍可用
- 黑名单优先级最高（仅次于设备管理器）：黑名单应用在任何情况下都被拦截

## 8. 报告与数据

### 8.1 数据采集

- **采集频率**：每 5 分钟采集一次前台应用使用时长
- **数据精度**：精确到分钟
- **存储加密**：所有数据通过 SQLCipher AES-256 加密存储

### 8.2 报告类型

| 报告类型 | 内容 | 导出格式 |
|----------|------|----------|
| 日报 | 当日各应用使用时长、分类统计 | TXT / JSON |
| 周报 | 近 7 天使用趋势、日均值、分类占比 | TXT / JSON |

### 8.3 数据存储路径

| 平台 | 路径 |
|------|------|
| Windows | `%LOCALAPPDATA%\XiaopacaiParent\data\xiaopacai.db` |
| Android | `/data/data/com.xiaopacai.child/databases/xiaopacai_guardian.db` |

## 9. 安全与隐私

### 9.1 数据加密

- **数据库**：SQLCipher AES-256-CBC 加密
- **密码存储**：PBKDF2-HMAC-SHA256（10 万次迭代）+ 随机盐值
- **传输加密**：TLS 1.3 加密 P2P 通道
- **完整性校验**：HMAC-SHA256 校验数据完整性

### 9.2 防绕过措施

| 措施 | 说明 |
|------|------|
| 设备管理器 | 防止卸载应用、清除数据 |
| 无障碍服务监控 | 检测设置页面打开等绕过行为 |
| 进程守护 | 前台服务持续运行，防止被系统杀死 |
| 开机自启 | 设备重启后自动恢复守护 |
| 密码保护 | 关键操作需家长密码验证 |

### 9.3 数据隐私

- 所有使用数据仅存储在本地加密数据库中
- P2P 通信仅在局域网内进行，数据不上传云端
- 日志中敏感信息（设备指纹等）自动脱敏

## 10. 常见问题

### Q1：儿童端提示"未连接到家长端"

**原因**：网络不通或防火墙阻挡
**解决**：
1. 确认双方在同一 Wi-Fi 网络
2. 检查 Windows 防火墙是否允许 XiaopacaiParent.exe
3. 重启双方应用
4. 在家长端「设备列表」中点击「重新连接」

### Q2：应用拦截不生效

**原因**：无障碍服务未启用或被系统回收
**解决**：
1. 检查「设置 → 无障碍 → 小趴菜守护」是否开启
2. 在儿童端主界面点击「重新启用服务」
3. 部分国产手机需在「电池优化」中将小趴菜设为「不优化」

### Q3：忘记家长密码

**解决**：在家长端「设置 → 安全 → 重置密码」使用旧密码重置。如完全忘记，需卸载后重新安装配对（所有历史数据将丢失）。

### Q4：配对二维码扫描失败

**解决**：
1. 确保儿童端相机权限已授予
2. 调整二维码大小和距离
3. 如仍失败，可手动在儿童端输入家长端显示的 6 位配对码

### Q5：Windows 端无法启动

**解决**：
1. 确认已安装 .NET 8 Desktop Runtime
2. 检查 `%LOCALAPPDATA%\XiaopacaiParent\` 目录是否有写入权限
3. 尝试以管理员身份运行
4. 查看 Windows 事件查看器中的应用程序日志

### Q6：Android 端耗电严重

**原因**：前台服务持续运行 + 定期采集
**优化**：
1. 采集间隔默认 5 分钟，可在家长端调大间隔
2. 确保已开启「电池优化 → 不优化」
3. 关闭不需要的调试日志（家长端设置）
